# 🚢 Batalha Naval em C

Projeto desenvolvido em linguagem C com o objetivo de praticar lógica de programação, estruturas de dados e manipulação de matrizes.

## 🚀 Descrição

Este projeto simula um tabuleiro de Batalha Naval (10x10), onde navios são posicionados em diferentes direções:

- Vertical
- Horizontal
- Diagonal
- Diagonal invertida

## 🧠 Funcionalidades

- Criação de um tabuleiro 10x10 utilizando matriz 2D
- Inicialização do tabuleiro com valores padrão (água)
- Posicionamento manual de navios
- Impressão organizada do tabuleiro no terminal

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão (`stdio.h`)

## 📚 Conceitos aplicados

- Matrizes (arrays bidimensionais)
- Estruturas de repetição (`for`)
- Lógica de programação
- Organização de dados
- Representação de estado (água/navio)
